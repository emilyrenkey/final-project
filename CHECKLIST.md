# Final project checklist

40 points in eight parts. The assignment page describes each one.

- [ ] Question (4): question, prediction written first, data source, what one row is, units
- [ ] Data (4): relative-path import, missing values checked, analysis table built with the tidyverse
- [ ] Figures (4): the data, the possible worlds with the observed number, units, captions, accessible colors
- [ ] Measurement (6): one dataset in, one number out; checked by hand; one or two sentences on why this number answers your question; at least two groups, nest + map_vec() for one number per group
- [ ] Possible worlds (10): two or three sentences on how you build the worlds and why, expand_grid() + map() + set.seed(), at least 100 runs, one world shown, total simulation time recorded with tictoc
- [ ] Answer (4): the answer, your interpretation, one limitation, one next step
- [ ] Report (4): renders after Restart R, cross-references, two citations, renv.lock
- [ ] GitHub (4): repository with README and .gitignore, at least one commit pushed

Before you submit:
- [ ] Repository link in the report
- [ ] The zip has .qmd, .html, references.bib, data/, renv.lock, .Rprofile, renv/activate.R, .gitignore
